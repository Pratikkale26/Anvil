## What to AVOID in live demo (pre-emptive list)

| Pattern | Why | Workaround |
|---|---|---|
| External CPIs to **Pyth / Switchboard** | `cpi_pyth_read_price` IR kind not emitted; calls become `TODO(manual)` stubs | Don't paste Pyth-using programs; use one of the 4 picks |
| External CPIs to **Metaplex Token Metadata + Core** | Same gap (grant M3, ~5 weeks) | Avoid mint-metadata flows in the demo |
| `#[account(zero_copy)]` (Drift / Mango shape) | Not supported; new IR kind needed | Don't demo zero-copy programs |
| **Token-2022 extensions** (transfer-fee, transfer-hook, confidential) | tracked-ceiling only — compiles with stubs but runtime semantics differ | Avoid T22 ext programs |
| Multi-file Anchor with **free-function delegation** in `instructions::` module | `ctx` references leak (free fn isn't inlined like impl methods are) | E.g. `tokens/token-swap` from solana-developers/program-examples — DON'T paste live |
| **`has_one`** constraint enforcement | Some constraint patterns don't emit the runtime check | Avoid programs using `has_one = X` if the runtime check matters for demo |
| Programs with **`use fixed::types::I64F64`** or other crates Anvil's scaffold doesn't add | Build fails on missing dep | Stick to programs whose deps fit `borsh + pinocchio[-system,-token]` |
